# Bomberolho

Jogo de batalha em arena, com tema de oftalmologia, para crianças jogarem no navegador do celular na sala de espera.

Em construção. O plano completo está em [PLAN.md](PLAN.md).

## Rodar localmente

```bash
node dev-server.mjs --port 7200
```

Depois abra `http://localhost:7200/bomberolho/`.
